Building Sandwich Studio

Human Decisions, AI Implementation, and the Bugs Between

Summary

Sandwich Studio is a creator-directed workspace for structured comic production: story and character references, artwork handling, editable lettering, revisions, previews and explicit review states. It began as an attempt to tell a comic story with AI-generated images that stay consistent from page to page, and became a much larger engineering project.

The case study asks what it takes to keep a human in control while AI agents help to build and operate creative software. The workspace was designed so that a person can work in the browser interface or instruct an agent to carry out the same relevant operations. Carrying out an edit and approving it are kept as separate steps.

What it covers

  • Roles and decisions: AI explores options, the human decides and AI agents implement, following the Human Sandwich Model.
  • Agent access: how a shared set of actions lets a person and an agent operate the same workspace.
  • Reliability: blank artwork, interrupted writes, unsafe pending changes and an approval step that had to be redesigned, including defects that earlier passing tests had missed.
  • Agent trials: a session that started in the wrong project, the human correction, and the separate approval that followed.
  • Lessons: delegation as a system-design problem, negative testing, and how too many procedural steps can hide the decisions that matter.

How to read it

This is one documented case. It is not proof that this workflow is better than others. Test counts and technical outcomes in the document are attributed to the project's own records. This page offers the publication, not the software.

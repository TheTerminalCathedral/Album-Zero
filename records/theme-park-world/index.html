Theme Park World on Windows 11

Project by:
Dan Almer Jensen
Status:
Beta 1
Tested on:
One Windows 11 PC, English 2.0

An unofficial wrapper mod for the 1999 game Theme Park World, also sold as Sim Theme Park, made with AI under human direction. It contains no game files.

Why it was started

Theme Park World was Dan's favourite game as a kid. Dan wanted to play it again and couldn't get it to run on Windows 11, so Dan tried the Human Sandwich Model on the problem. Together with AI, Dan worked through possible solutions and got the game running again.

What the mod does

  • Runs the game's Direct3D through Direct3D 9
  • Gives the game a real window that can be moved, resized at 4:3 and minimized
  • Keeps the mouse in the window; Ctrl+Alt frees it
  • Limits the game to 30 frames per second, because it ran too fast at 60
  • Avoids crashes seen at the screen edge and when entering a park (the second fix has had limited retesting)

What it needs

Your own copy of the game, and that copy must already start on your PC. The original discs use SafeDisc copy protection, which Windows 10 and 11 do not support. The mod does not remove or work around copy protection.

Limits

It was made for and tested on one PC, and the release setup was tested for a short session only. The game can freeze, especially at the lowest game speed, and the cause is unknown. Other PCs may need changes, and success is not guaranteed. Back up the game and your saves.

The project is not affiliated with EA or Bullfrog, and it is not an official patch.

Source

Instructions, source changes and the beta release: TheTerminalCathedral/theme-park-world-win11 on GitHub. It builds on dxwrapper.
